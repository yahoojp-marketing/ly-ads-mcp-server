# Contributing

> This guide is also available in [Japanese](CONTRIBUTING.ja.md).

Thank you for your interest in contributing to this project.

This project is developed and maintained by the LY Ads product team.

We do not accept external pull requests or code contributions.
Submitted pull requests will generally be closed without review.

If you discover a bug or other issue, or if you have any questions, please contact us through the [LY Corporation Business Services contact page](https://www.lycbiz.jp/en/contact/).

To report a security vulnerability, please follow our [Security Policy](SECURITY.md).
